# STATUS.md — пульт Степана

> Читай только этот файл. Всё остальное — для агентов.

## Как пользоваться

Открой режим **🎬 Продюсер** и одной фразой напиши цель и срок,
например: «закончить сайт сегодня до 22:00». Дальше агенты работают
сами; от тебя — выбор концепта (минута) и в конце слово «пуш».
Вопросы тебе агенты пишут в этом файле, пачкой, не больше трёх,
у каждого есть ответ по умолчанию — можно не отвечать, работа идёт
по умолчанию.

## Цель и срок

- **Цель**: сайт, на котором клиенту хочется оставить заявку.
- **Срок**: не задан.

## Нужно от вас

1. **Автоодобрение.** В настройках расширения (шестерёнка в панели
   чата) → «Автоодобрение / Auto-approve» → включить галочки: чтение,
   запись, браузер, MCP, подзадачи, команды. Запись в защищённые файлы
   (.roomodes, AGENTS.md, .vscode) всё равно попросит клик — это защита
   расширения.
   *По умолчанию: агенты ждут твоих кликов.*

2. **Ключ API aitunnel.** Добавь его в файл `.env` под именем
   `AITUNNEL_API_KEY` (ключ в чат не присылай). Нужен для генерации
   картинок по реальным фото и для второй модели Эксперту.
   *По умолчанию: работаем без генерации, концепты делаем
   HTML-макетами.*

3. **Яндекс.Метрика.** Есть ли счётчик от Тильды, который можно
   перенести, или создать новый в аккаунте Яндекса и прислать номер?
   Агенты заранее подготовят код и цели (заявка, звонок, клик по
   мессенджерам, использование калькулятора).
   *По умолчанию: агенты вставят заглушку с комментарием, номер
   добавишь потом.*
