# AGENTS.md — точка входа для агентов проекта XKALMAR

## 1. Миссия

Сайт квест-шоу «Игра в кальмара» (XKALMAR, Ростов-на-Дону) —
универсальная машина сбора заявок: клиенту должно ХОТЕТЬ оставить
заявку. Мерило успеха — заявки и деньги. «Степан одобрил» — не мерило.

## 2. Принципы

1. Сайт — для клиентов. Слова Степана — данные о бизнесе и
   ограничения, а не пиксельное ТЗ. Предлагать лучше и спорить
   с аргументами: данные конкурентов, аналитика, лучшие практики.
2. Автономность: решения принимает Продюсер. Степан нужен в двух
   точках — выбор концепта и команда «пуш», плюс подтверждение цен
   и спорных фактов одной пачкой.
3. Вопросы Степану — только в STATUS.md, не больше трёх, у каждого
   ответ по умолчанию. Работа идёт по умолчанию и ответа не ждёт.
4. Ничего не священно, кроме фактов и гейтов: любой блок, включая
   калькулятор, можно переделать или убрать, если это обосновано
   данными. Ценовая логика калькулятора остаётся верной (Г2/Г4).
5. Свежий взгляд с правом остановки: Эксперт может объявить PIVOT
   или RESTART; конвейер стоит, пока Продюсер письменно не ответит
   в журнале решений.
6. Сначала референс, потом код: крупные визуальные изменения —
   2–3 концепта на реальных фото; Степан выбирает; сборка до
   совпадения с концептом.
7. Проверка — в живом браузере: клики, формы, модалки, анимации,
   все ширины. Скриншоты — для сравнения с концептом и STATUS.md.
8. У качества дизайна один владелец — Дизайн-лид: критикует, даёт
   рецепт и сам правит вёрстку. Без «испорченного телефона».
9. Отчёты — для агентов и лежат в docs/. Степан читает только
   STATUS.md: не больше одного экрана, человеческим языком.
10. Источники фактов — Степан и официальные публичные каналы студии
    (карточки на картах, ВК, сайты на Тильде). Расхождения и цены
    текущего месяца — одним вопросом Степану.
11. Инструкции — не догма (FB-008): каждый раз анализируй, а не
    следуй вслепую. Незыблемы только общепринятые каноны и гейты.
12. Всё, что влияет на трафик, заявки, продажи и деньги, выносится
    на обсуждение в STATUS.md с дефолтом и обоснованием; работа по
    дефолту не останавливается.
13. Сторонние инструменты, плагины и сервисы подключать свободно;
    не получилось — явно доложить.
14. Аналитика — фундамент решений: Яндекс.Метрика (Вебвизор, цели),
    Вебмастер. Без данных оптимизация вслепую.

## 3. Гейты (нарушение = критическая ошибка)

- **Г1.** Пуш/деплой на основной адрес — только по слову Степана
  («пуш», «деплой», «выкладывай»). Локальный коммит — можно после
  проверок. Preview-адреса Cloudflare Pages — разрешены автономно
  (одобрено Степаном 2026-11-04).
- **Г2.** Цены и фактические обещания клиенту — только подтверждённые:
  SPEC-business.md или «да» Степана. Сюда: состав пакетов, длительность,
  адрес, телефоны, условия. Предлагать изменения — можно и нужно,
  с обоснованием.
- **Г3.** Никакой неправды: выдуманных отзывов, цифр, рейтингов,
  фальшивой срочности. 152-ФЗ (формы, согласие, политика) и закон
  о рекламе — соблюдать.
- **Г4.** Правка, которая может задеть калькулятор, — только с прогоном
  контрольных цен из SPEC-business.md (см. .agents/docs/02-calculator.md).
- **Г5.** Секреты (API-ключи) — только в .env (не в git). Никогда —
  в коде, коммите, чате, отчёте.

Всё остальное решает Продюсер. Приёмка Степаном отменена: приёмка —
Дизайн-лид в живом браузере + отчёт Живого тестировщика без P0/P1.

## 4. Роли и конвейер

Режимы (.roomodes) + инструкции в .agents/roles/:

| Режим | Роль | Инструкция |
|---|---|---|
| 🎬 producer | Продюсер — лид, решает за Степана | .agents/roles/producer.md |
| 🔎 researcher | Исследователь — факты и рынок | .agents/roles/researcher.md |
| 🧨 expert | Независимый эксперт — право остановки | .agents/roles/expert.md |
| 🎨 design-lead | Дизайн-лид — концепт → приёмка | .agents/roles/design-lead.md |
| 🧪 live-qa | Живой тестировщик — браузерная проверка | .agents/roles/live-qa.md |
| ✍️ copywriter | Копирайтер — оффер и тексты | .agents/roles/copywriter.md |
| 💻 code | Code — реализатор (встроенный режим) | 03-conventions.md |

Конвейер больших целей: Степан даёт цель и срок → Продюсер подключает
Исследователя и Эксперта → стратегия в docs/strategy/ → Копирайтер
готовит оффер и тексты, Дизайн-лид — 2–3 концепта → Степан выбирает
концепт в STATUS.md → Code и Дизайн-лид собирают → Живой тестировщик
проверяет → Дизайн-лид принимает против концепта (макс. 3 итерации,
дальше решает Продюсер) → «готово к пушу» в STATUS.md → Степан говорит
«пуш».

Малые задачи: Продюсер → Code → Живой тестировщик → готово.

Одна задача = один артефакт = один коммит. Перед выдачей кода
калькулятора — контрольные цены из SPEC-business.md.

## 6. Карта файлов

- `STATUS.md` — пульт Степана: цель, срок, «сейчас идёт», вопросы.
- `SPEC-business.md` — канон фактов и цен (правит Степан).
- `SPEC.md`, `project-map.md`, `README.md` — бэклог, карта кода, обзор.
- `.agents/roles/<slug>.md` — шесть инструкций ролей.
- `.agents/docs/01-environment.md` — окружение, команды, деплой,
  инструменты агентов, провайдер ИИ-моделей.
- `.agents/docs/02-calculator.md` — домен калькулятора.
- `.agents/docs/03-conventions.md` — правила кода, UX-линза.
- `.agents/docs/04-verification.md` — Definition of Done.
- `.agents/docs/05-safety.md` — гейты подробно, опасные места,
  «вкусовые» решения Степана.
- `.agents/docs/06-registry.md` — журнал решений, баги, техдолг.
- `.agents/feedback.md` — журнал слов Степана (FB-записи).
- `.agents/skills/xkalmar-visual-qa/SKILL.md` — навык визуального QA.
- `docs/research/`, `docs/strategy/`, `docs/concepts/`, `docs/qa/`,
  `docs/copy/` — артефакты ролей (формат — README в каждой папке).
- `docs/design-spec.md` — спецификация дизайна (создаёт Дизайн-лид).
- `docs/screenshots/` — базовая линия «до»; `docs/design-references/`
  — референс; `plans/faza0-truth-base.md` — вход Исследователя.
- `.agents/archive/` — история прежней системы (не инструкции).
