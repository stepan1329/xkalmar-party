# 03-conventions.md — правила кода, UX-линза

## UX-линза (применять к любой формулировке и UI)

Покупатели — родители детей 6–12 лет. Они НЕ обязаны знать специфику
(что такое «банкет», «под ключ», «ярмарка», «квест-шоу» как термин).
Проверка каждой формулировки:
1. Родитель понимает её за 3 секунды без знания специфики?
2. Видно, куда нажать и что произойдёт после нажатия?
3. Путь от посещения до заявки не содержит ступора?

Вариант формулировки, удовлетворяющий линзе, показывать Степану на
оценку. Спорное — FIXME-REVIEW, не выдумывать.

## Astro и TypeScript

- Frontmatter .astro: ровно две линии `---` на собственных строках,
  ничего до первой. Комментарий во frontmatter — одна строка
  (многострочный протекает на страницу).
- В `<script>` внутри .astro — `// @ts-nocheck` первой строкой.
- TS strict. Один файл — одна цель.

## Разметка и JS

- hidden и inline style.display НЕ смешивать. Элементами, которыми
  управляет JS через style.display, в разметке ставить
  `style="display:none"`, не `hidden`.
- События-шины: drcalc-update, drcalc-refresh и любые новые —
  слушать и отправлять на document, не на window.
- Radio-deselect: признак повторного клика — сравнение значений
  (String(curValue) === inp.value), не inp.checked. После снятия
  выбора — обязательно перерисовать блок (syncExt / sync*).

## Кнопки и панели

- Кнопки: `-webkit-tap-highlight-color: transparent;`
  `:focus:not(:focus-visible) { outline: none; }`
  `:focus-visible { outline: 2px solid #0AD9C6; }`
- Panels без `width: 100%` там, где уже растянуты grid/flex — иначе
  с боковыми margin даёт overflow.
