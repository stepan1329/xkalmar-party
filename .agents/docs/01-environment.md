# 01-environment.md — окружение, команды, деплой

## Стек

- Astro 7.4.2, Vite 8.3.5, Node ≥ 22.23.4, TypeScript strict.
- Без UI-фреймворков. Стили — чистый CSS внутри `.astro`.

## Установка и запуск

```bash
npm install              # установка зависимостей
astro dev --background   # dev-сервер в фоне (localhost:4321)
astro dev status         # статус фонового сервера
astro dev logs           # логи фонового сервера
astro dev stop           # остановка
npm run build            # production-сборка в ./dist/
npm run preview          # предпросмотр сборки
npm run astro check      # проверка типов (обязательна перед сдачей)
```

Правила:
- Dev-сервер держать в фоне (`astro dev --background`), не блокировать терминал.
- `astro check` — обязательный шаг верификации (см. 04-verification.md).

## Деплой (ГЕЙТ)

**Push только по явной команде Степана** (слово «пуш», «деплой»,
«выкладывай»). Степан — не программист и деплой не выполняет: пуш
делает агент, но ТОЛЬКО после его команды и после прохождения всех
проверок и визуальной приёмки.

Процесс деплоя (автоматический, без ручных шагов):
1. git commit (локально, после верификации).
2. Явная команда Степана на пуш.
3. git push → Cloudflare Pages автодеплой.
4. Проверить результат: https://xkalmar-party.pages.dev
5. Отчёт Степану человеческим языком.

Нарушение гейта (самовольный пуш) — критическая ошибка.
