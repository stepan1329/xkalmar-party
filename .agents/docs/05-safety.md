# 05-safety.md — гейты подробно, опасные места, вкусовые решения

> Читать ПЕРЕД любой задачей. Нарушение гейтов — критическая ошибка.

## Гейты (кратко из AGENTS.md, здесь — подробно)

- **Г1. Пуш/деплой на основной адрес** — только по слову Степана
  («пуш», «деплой», «выкладывай»). Локальный коммит — можно после
  проверок. Preview-адреса Cloudflare Pages — разрешены автономно.
- **Г2. Цены и фактические обещания клиенту** — только подтверждённые:
  SPEC-business.md или «да» Степана. Сюда: состав пакетов,
  длительность, адрес, телефоны, условия. Предлагать изменения цен
  и офферов — можно и нужно, с обоснованием; публиковать — после
  подтверждения.
- **Г3. Никакой неправды**: выдуманных отзывов, цифр, рейтингов,
  фальшивой срочности. 152-ФЗ (формы, согласие, политика) и закон
  о рекламе — соблюдать.
- **Г4. Калькулятор**: правка, которая может задеть калькулятор,
  — только с прогоном контрольных цен (02-calculator.md,
  04-verification.md п.1).
- **Г5. Секреты**: API-ключи только в .env (не в git). Никогда —
  в коде, коммите, чате, отчёте.

Всё остальное решает Продюсер.

## Вкусовые решения Степана (ранее «не возвращать удалённое»)

Это не запреты, а зафиксированный вкус Степана. Продюсер может
пересмотреть любое из них — с обоснованием в журнале решений
(06-registry.md) и строкой в STATUS.md. Пока решение не пересмотрено,
самовольно возвращать не следует:

- Правая колонка «Ваш тариф» — удалена.
- Бар — заменён пиллом + шторкой.
- Absolute-бейджи, toprow — удалены.
- Опции «без ярмарки» — удалены.
- Фиксированное «Банкет под ключ 6 000 ₽» — удалено.

## Регрессионно-опасные места калькулятора
(правка рядом = прогон контрольных цен, Г4)

- `calculate()` — единственный источник цен, формулы выверены.
- `pick()` / `pushSnapshot()` — перенос в форму; silent-режим.
- `restoreCalcState()` — восстановление из localStorage.
- `syncExt()` — ярмарка.
- `recalcAll()` — порядок синхронизации (syncProgramUI первой строкой).
- Слушатель `drcalc-refresh` — должен быть на document, НЕ на window
  (CustomEvent не всплывает; причина бага этапа А).
- Логика еды: единая формула для всех тарифов с едой (на 6 включено,
  сверх +1 000/чел). Исключения для отдельных пакетов — только через
  подтверждение Степана (Г2).

## Модель поведения при конфликте

- Код/док против факта Степана или публичного канала студии → факт
  прав; расхождение фиксировать в 06-registry.md и вопросом Степану
  (пачкой, с дефолтом).
- Спорная инструкция → FIXME-REVIEW, не выдумывать компромисс.
- Известный баг из 06-registry.md с пометкой «отложен» → не чинить
  самовольно (решение о продлении отлагательства — Продюсер).

## Чего не делать с документацией

- Не создавать новые md-файлы «на всякий случай» — карта файлов
  зафиксирована в AGENTS.md.
- Не переписывать факты SPEC-business.md — правит Степан (или агент
  по его явному заданию); формулировки может улучшать Копирайтер,
  факты не меняя.
- Архив (.agents/archive/) — история, не инструкции: не читать как
  руководство, не возвращать в рабочие папки без решения Продюсера.
