# docs/concepts/ — концепты дизайна (design-lead)

Крупные визуальные изменения начинаются с 2–3 концептов на реальных
фото из public/photos. Степан выбирает концепт в STATUS.md.

- **Именование**: папка `<дата>/`, внутри `concept-a.md`,
  `concept-b.md`, `concept-c.md` и скриншоты `a-1440.png`,
  `a-390.png` и т.п.
- **Рабочие страницы концептов**: src/pages/concepts/<a|b|c>.astro
  (noindex, на основную страницу не влияют).
- **В каждом концепте**: идея одной строкой + чем цепляет клиента.
- Выбранный концепт превращается в спецификацию docs/design-spec.md.
