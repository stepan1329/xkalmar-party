Артефакты исследования рынка и фактов о XKALMAR.

- **Именование файлов**: `<дата>-<тема>.md`, например
  `2026-11-05-konkurenty-rostov.md`. Скриншоты источников —
  в `assets/`.
- **Порядок в файле**: резюме на 10 строк → таблицы →
  «10 выводов для сайта» (каждый с доказательством) →
  «Что уточнить у Степана» (≤3 пункта).
- **Правило**: каждое утверждение с URL; без URL — пометка «гипотеза».
  Тексты конкурентов не копировать дословно.
