# Дизайн-система XKALMAR v2 — спецификация

> **Дата:** 2026-11-03 · **Статус:** НА УТВЕРЖДЕНИЕ Степаном.
> Заменяет `docs/design-system.md` (DRAFT-снимок «как было»).
> Основа: бренд-палитра XKALMAR + две темы. Референсы: Apple HIG
> (ясность, иерархия), Material 3 (токены, состояния), Яндекс
> (плотность, CTA), Мир Квестов (каталог, карточка квеста).
> Границы: НЕ меняет логику калькулятора, цены, тексты SPEC-business.

## 1. Принципы

1. **Человек за 3 секунды** — понятно, что это, сколько стоит, куда нажать.
2. **Одна primary-кнопка на экран** — остальные действия тише.
3. **Токены, не цвета** — компоненты используют смысловые роли
   (`--color-cta`), а не HEX. Смена темы или бренда = смена токенов.
4. **Состояния обязательны** — у каждого интерактивного элемента:
   default / hover / active / focus-visible / disabled / selected.
5. **Мобильный первый** — тап-зона ≥ 44×44px, шрифт ≥ 16px в полях
   (иначе iOS зумит), safe-area учтён.
6. **Скорость = SEO = деньги** — без внешних шрифтов, тяжёлых
   iframe-виджетов и рекламы на коммерческих страницах.

## 2. Архитектура токенов

Три слоя: примитивы (HEX) → семантика (роль) → компонент.
Все переменные — в `:root`, тема переключается атрибутом
`data-theme="dark" | "light"` на `<html>`.

### 3.4 Контраст (проверить в Этапе 2 автоматически)

- Текст body: ≥ 4.5:1 к фону. Мелкий текст `.55` на тёмном — запрет.
- Текст на CTA: белый на `#C30067` = 5.2:1 ✅.
- focus-visible: 3:1 к фону (бирюза на тёмном ✅, teal-deep на светлом ✅).

## 4. Типографика (системный стек, без внешних шрифтов)

```
-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
'Helvetica Neue', Arial, sans-serif
```

| Токен | Размер | Вес | LH | Использование |
|-------|--------|-----|----|---------------|
| --font-display | clamp(32px, 6vw, 56px) | 800 | 1.12 | h1 hero |
| --font-h2 | clamp(24px, 4vw, 34px) | 700 | 1.25 | заголовки секций |
| --font-h3 | 20px | 700 | 1.3 | подзаголовки карточек-блоков |
| --font-title | 17px | 700 | 1.35 | названия карточек |
| --font-body | 16px | 400 | 1.6 | основной текст |
| --font-meta | 14px | 500 | 1.5 | подписи, meta |
| --font-hint | 12px | 400 | 1.45 | подсказки (не для действий) |
| --font-price | 28px | 800 | 1.0 | цены |
| --font-cta | 16px | 700 | 1.0 | текст кнопок |

Правила: h1 один на страницу; em-акцент в h1 = --cta; текст
абзацев ≤ 70 символов в строке; числа цен с неразрывным пробелом.

## 5. Шкала отступов (кратно 4)

`--space-1..10: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128`

- Секция: `--space-8` / 64px вертикально (мобайл: --space-6 / 48px).
- Контейнер `.wrap`: max-width 1100px, паддинг 24px (мобайл 16px).
- Gap сеток: 16px (мобайл 12px).
- Внутри карточек: 24px (мобайл 20px).

## 6. Радиусы — ровно 4 значения

| Токен | Значение | Использование |
|-------|----------|---------------|
| --radius-s | 10px | поля ввода, чипы, мини-кнопки |
| --radius-m | 16px | карточки, модалки |
| --radius-l | 24px | крупные контейнеры, hero |
| --radius-pill | 999px | кнопки, бейджи, FAB |

## 7. Тени (elevation) — 3 уровня

| Токен | Значение | Когда |
|-------|----------|-------|
| --elev-1 | 0 2px 8px rgba(2,20,18,.12) | карточки в покое, hover-приподъём |
| --elev-2 | 0 8px 24px rgba(2,20,18,.18) | sticky-элементы, пилл, FAB |
| --elev-3 | 0 16px 48px rgba(2,20,18,.30) | модалки, лайтбокс |

На тёмной теме тени слабые — глубину дают уровни фона
(surface → raised) и граница --line.

## 8. Движение

- --dur-fast: 150ms (hover, фокус, мелкие изменения)
- --dur-normal: 220ms (раскрытия, модалки, шторка)
- --ease: cubic-bezier(.2, .8, .2, 1)
- `prefers-reduced-motion: reduce` — отключить трансформы и анимации.
- Появление секций: без scroll-анимаций на старте (скорость важнее).

## 9. Брейкпоинты

`360 · 768 · 1024 · 1280` (мобайл-first). Проверка агента: 1440,
1024, 768, 390, 360.

## 10. Кнопки

### Primary (--cta)
- Пилюля, padding: L 16px 36px / M 13px 28px / S 10px 20px.
- Состояния: hover --cta-hover · active --cta-press (scale .98) ·
  focus-visible outline 2px --accent offset 2px · disabled opacity .5.
- Никаких теней — цвет и вес сами по себе сильные.

### Secondary (обводка)
- Прозрачная, border 2px: тёмная тема — rgba(255,255,255,.6),
  светлая — `#0A2A27`. Hover: заливка rgba 10%.

### Ghost / text-link
- Только текст, цвет --accent, underline на hover.

Правило: на экране одна Primary. Hero: Primary «Рассчитать
праздник» + Ghost «Что это за формат?».

## 11. Компоненты

### 11.1 Карточка (card)
- --surface, --radius-m, padding 24px, --elev-1, hover: translateY(-2px)
  + --elev-2, transition --dur-fast.
- Product-карточка пакета (калькулятор): превью-фото сверху
  (16:10, object-fit cover), название (--font-title), строка
  включений (--font-meta, максимум 4 пункта + «и ещё N»), цена
  (--font-price) внизу, бейджи поверх фото (слева сверху).
  Выбрана: border 2px --cta. Тап по карточке = выбор.

### 11.2 Чип (мета-факт)
- --radius-pill, --radius-s фон --surface, --font-meta.
  Пример в hero: `6–12 лет` · `90 минут` · `от 15 000 ₽`.

### 11.3 Бейдж доверия
- Пилюля на --cta («Выбирают чаще всего») или --accent
  («Год назад обновили программу») поверх карточек.

### 11.4 Рейтинг-плашка
- Звёзды --star + «5.0 · 154 оценки на Яндекс.Картах» (--font-meta)
  + ссылка. Вставки: hero, блок отзывов, перед формой.

### 11.5 Якорное подменю (навигация по странице)
- Sticky под шапкой, --surface + --elev-2, табы --font-meta,
  активный таб: underline 2px --cta. На мобайле — горизонтальный
  скролл, без скроллбара.

### 11.6 FAB «Связаться»
- Круг --radius-pill 56px, правый нижний угол
  (bottom: 16px + safe-area, right: 16px), иконка чата,
  --elev-2. Появляется после прокрутки первого экрана
  (opacity+translateY, --dur-normal). Раскрытие: вертикальный
  стек из 4 кнопок: Позвонить / МАКС / Telegram / WhatsApp
  (приоритет сверху вниз). Клик по любой = цель Метрики.
- На странице ДР FAB не конфликтует с пиллом корзины: пилл выше,
  FAB левее края (или скрыт, когда шторка открыта — решаем в Этапе 2).

### 11.7 Футер
- Тёмная тема: --bg-alt. Колонки: Поводы (ДР, Выпускной, Выход
  с классом, Новый год, Корпоратив, Лагерь) / Контакты (телефон,
  МАКС, Telegram, WhatsApp, ВК, адрес, ссылка на карту) /
  Инфо (Политика, Оферта если будет). Низ: © + ИП + «Сделано в
  Ростове-на-Дону». Мобайл: колонки в столбец, ссылки крупные
  (тап 44px).

### 11.8 Карта (замена iframe)
- Статичное изображение с меткой в --radius-m контейнере,
  подпись адреса --font-meta, кнопка-ссылка «Открыть в
  Яндекс.Картах» (Primary-S). Никаких iframe на посадочных.

### 11.9 Формы
- Поле: --radius-s, фон --surface (тёмная) / neutral-50 (светлая),
  border --line, focus: border --accent + outline.
- font-size 16px (анти-зум iOS). Ошибки: inline, красный `#FF5470`
  (токен --error), под полем, без alert().
- Кнопка отправки: Primary-M на всю ширину на мобайле.

### 11.10 Калькулятор — вписывание в систему (вид, не логика)
- Шапка секции: h2 + подпись «за минуту посчитаете точную цену».
- Пакеты = product-карточки (11.1) в сетке 3 → 1 колонка.
- Шаги настроек: --surface, --radius-m, единые --radius-s поля.
- Пилл корзины: --elev-2, --radius-pill, dirty-точка --cta.
- Шторка: --surface-raised, --elev-3, сверху скругление 24px.
- Всё прежнее поведение (выбор/снятие, события, localStorage) —
  не трогается.

## 12. Доступность

- Focus-visible везде (не убирать, а оформлять).
- aria: лайтбокс/модалки — role=dialog, aria-modal, focus-trap
  (Спринт 4 SPEC); FAB — aria-label «Связаться с нами».
- Изображения: осмысленный alt (не «фото 1»).
- Ссылки-якоря работают без JS.

## 13. Что фиксируем как НЕ-изменяемое

- Палитра бренда: --cta #C30067, тёмный #032E2B, бирюза.
- Логика калькулятора и контрольные цены (SPEC-business).
- Канон текстов (SPEC-business) — только через явное задание.
- События на document (drcalc-*), localStorage-ключи.

## 14. План миграции (Этап 2)

1. `src/styles/tokens.css` — примитивы + обе темы, подключение в Base.
2. Base.astro: header (sticky), footer новый, focus-правила.
3. index.astro: секции на токены, порядок блоков по аудиту —

4. Calculator.astro/RequestForm.astro: вид на токены, логика нет,

5. FAB, якорное меню, статичная карта — новые компоненты.
