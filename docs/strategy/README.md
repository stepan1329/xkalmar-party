# docs/strategy/ — стратегия и вердикты

- **Эксперт** (expert): `expert-<дата>.md` — вердикт CONTINUE /
  PIVOT / RESTART, пять главных причин, «идеальная страница»,
  что выбросить/сохранить/добавить, роль калькулятора, риски,
  метрики успеха.
- **Продюсер** (producer): `<дата>-<тема>.md` — стратегия большой
  цели: план вех, распределение по ролям, критерии готовности.

Именование: `<дата>-<тема>.md` или `expert-<дата>.md`.
Решения по вердиктам Продюсер фиксирует в .agents/docs/06-registry.md.
