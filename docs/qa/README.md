# docs/qa/ — отчёты Живого тестировщика (live-qa)

- **Именование**: `live-<дата>.md`, например `live-2026-11-05.md`.
- **Формат**: таблица «сценарий → результат → доказательство
  (скриншот/консоль)»; скриншоты — в `assets/`.
- **Баги**: с шагами воспроизведения. P0 — ломает заявку; P1 — мешает;
  P2 — косметика. Задача готова, когда отчёт без P0/P1
  (см. 04-verification.md).
- Тестировщик сам не чинит, кроме тривиального по поручению Продюсера.
