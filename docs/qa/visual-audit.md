## 2. Обнаруженные проблемы

### 2.1 Галерея — дублирование контента

**Серьёзность:** средняя

**Проблема:** HTML содержит две полные галереи:
- Скрытая `.gallery` (10 фото) — видна по умолчанию
- Скрытая `#gallery-full` (55 фото) — видна после клика «Все фото»

Обе секции содержат `<h2>Фотогалерея</h2>` и `<p class="gallery__sub">`.
При раскрытии полной галереи на странице оказываются два заголовка «Фотогалерея».

**Рекомендация:** 
- Убрать дублирующий `<h2>` и `<p>` из `#gallery-full`
- Или использовать одну галерею с JS-раскрытием списка элементов

### 2.2 Галерея — пропущенные номера файлов

**Серьёзность:** низкая

**Проблема:** В `index.astro` используются файлы:
`squid-game-quest-1` через `squid-game-quest-38`, затем `40` (пропущен 39), затем `41-53`.

Файл `squid-game-quest-39.webp` отсутствует в `public/photos/`.

**Рекомендация:** Проверить, что пропуск осознанный. Если 39 — лишнее фото, оставить. Если ошибка — добавить.

### 2.3 Смешанные форматы изображений

**Серьёзность:** средняя

**Проблема:** В `public/photos/` присутствуют как `.webp`, так и `.jpg`/`.JPG` файлы.
В HTML используются только `.webp`, но оригиналы `.jpg`/`.JPG` занимают место в репозитории.

Также:
- `hero-mobil-1.JPG` (оригинал) + `hero-mobil-1.webp` (оптимизированный)
- `squid-game-quest-24.JPG` → `.webp`
- `squid-game-quest-25.JPG` → `.webp`
- `squid-game-quest-47.JPG` → `.webp`
- `squid-game-quest-49.JPG` → `.webp`
- `squid-game-quest-50.JPG` → `.webp`
- `squid-game-quest-51.JPG` → `.webp`
- `squid-game-quest-52.JPG` → `.webp`
- `squid-game-quest-53.JPG` → `.webp`

**Рекомендация:** `.jpg`/`.JPG` оригиналы можно удалить из репозитория, если они не нужны для повторной генерации `.webp`.

### 2.4 Hero-изображение — разные форматы

**Серьёзность:** низкая

**Проблема:** `hero-1.jpg` существует alongside `hero-1.webp`.
`hero-mobil-1.JPG` существует alongside `hero-mobil-1.webp`.

**Рекомендация:** Удалить `.jpg`/`.JPG` оригиналы, оставить только `.webp`.

### 2.5 Альтернативный текст — несоответствие

**Серьёзность:** низкая

**Проблема:** В превью-галерее `alt` короче, чем в `data-alt` для лайтбокса.

Пример:
- Превью: `alt="Квест-шоу для детей — дети в футболках с номерами"`
- Лайтбокс `data-alt`: `alt="Квест-шоу Игра в кальмара — дети в игровых футболках с номерами"`

**Рекомендация:** Унифицировать alt-тексты. Канонический — тот, что в `data-alt`.

### 2.6 Секция «Ярмарка игр» — рекламная формулировка

**Серьёзность:** низкая

**Проблема:** Подзаголовок секции:
> «После квеста трое ведущих одновременно проводят разные активности — и каждый ребёнок выбирает, что ему по душе.»

Это корректно, но формулировка «каждый ребёнок выбирает, что ему по душе» может восприниматься как рекламная.

**Рекомендация:** Проверить на соответствие тону SPEC.

### 2.7 Секция «Площадка» — видео без превью

**Серьёзность:** низкая

**Проблема:** Кнопки видео (`yamarka__video-btn`, `hallway__video-btn`) — это текстовые кнопки с иконкой ▶.
Нет визуального превью видео (thumbnail), как это обычно делают для видео-контента.

**Рекомендация:** Добавить thumbnail-изображение поверх кнопки видео для лучшего UX.

### 2.8 Карта — Yandex Maps iframe

**Серьёзность:** информационно

**Проблема:** iframe загружает тайлы, шрифты и рекламу Яндекс.Метрики.
Это увеличивает размер страницы и количество внешних запросов.

**Рекомендация:** При необходимости оптимизации — рассмотреть статичную карту-изображение с ссылкой на Яндекс.Карты.
